The Memory Drum

A quick memory experiment. You'll see a run of nonsense syllables one at a time, then recall as many as you can. About 3 minutes. Find a quiet moment and don't write anything down.

How it works

Read this first

  1. A window will show 12 nonsense syllables — ZOF, BAP, KEL… — one at a time.
  2. Just watch and try to remember them. Don't type or write anything yet.
  3. When they stop, type back every syllable you can recall, in any order.
They're meaningless on purpose — that's how Ebbinghaus measured pure memory. It's meant to feel hard.
You can't replay the run, so watch every syllable.
